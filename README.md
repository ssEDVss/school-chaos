# School Chaos

Игра на Godot (GDScript) про школьные шалости.

## О чём игра
В игре есть репутация, которая меняется в зависимости от твоих действий.
Нужно совершить как можно больше шалостей, чтобы учитель тебя не заметил.
Предметы, с которыми можно взаимодействовать, подсвечиваются. После
взаимодействия нужно как можно быстрее сесть на место, пока учитель
бежит к месту «преступления».

## Скачать
Версия для Windows: во вкладке Releases (справа на странице) скачай
SchoolChaos.exe и запусти.
Игра делалась под Android, пока доступна только версия для Windows.

## Технологии
Godot, GDScript

## Как открыть проект
Скачай репозиторий, в Godot нажми Import и выбери файл project.godot.
